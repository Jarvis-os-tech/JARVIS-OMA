# Jarvis voice capability wiring

The current voice session declares 119 skills from `skills/manifests/`. `DesktopSkills.execute` validates each declared tool and routes it to an adapter. `LiveVoice._execute_tool` now returns the actual result to the original Gemini Live function call, including operations that take longer than 150 ms. This is essential for any request where Jarvis needs to read data before speaking.

| Area | Jarvis voice route | Current scope |
| --- | --- | --- |
| Internet | `internet_search` | Brave Search API when `BRAVE_SEARCH_API_KEY` is configured, otherwise grounded Gemini Search with saved-account and model fallback. Both return source links. Stable encyclopedic questions can fall back to Wikipedia's public REST API; current news, prices, weather, and schedules cannot use this fallback. The Live model rejects built-in Search in its connection handshake, so Search is called as a separate voice tool. |
| Local files | `list_files`, `search_files`, `search_file_content`, `read_file`, plus write and management tools | Discovery tools default to the user's home directory when a spoken request omits a path. Jarvis can also begin in its current workspace. |
| GitHub | `github_connection_status`, `github_list_repositories`, `github_find_relevant_files`, `github_read_repository_files`, targeted file, issue and pull request tools | Jarvis can rank candidate paths from a pinned repository tree, read up to six files per batch, and base findings on numbered excerpts with commit-pinned links. Candidate ranking uses paths, so Jarvis must inspect contents before making claims. Individual file reads remain capped at 20,000 characters. |
| Google Workspace | Gmail, Calendar, Tasks, `drive_search_files`, `drive_get_file`, `drive_read_text_file`, `docs_read_document`, `sheets_get_spreadsheet`, `sheets_read_range` | Drive file discovery and metadata, small uploaded text files, Docs text including tabs and tables, and bounded Sheets ranges are wired through read-only Google APIs. Existing Gmail, Calendar, and Tasks access remains available. |
| Coding agents | `list_system_agents`, `delegate_agent`, job status and cancellation | Codex and Claude use visible terminals; OpenCode, Gemini, Hermes, and OMP use supervised CLI jobs. |
| Desktop, tasks, memory | Awareness/control, reminders, todos, task runner, proactive and memory tools | `inspect_screen` supplies OCR text and sends one bounded JPEG frame to the Live session when available. It falls back to OCR if frame delivery fails. |

Live checks on this installation confirmed GitHub account access, repository listing and README reading, plus Gmail search, Calendar listing, and Tasks listing. Google Drive authorization completed on October 16, 2026: `google_connection_status` reported `drive_connected: true`, a read-only Drive search succeeded, and a Sheets metadata read succeeded. Gemini Live connected with function tools after built-in Search was removed from the Live handshake. Grounded search now tries each saved Gemini account, using 3.8 Flash, 3.7 Flash, 3.6 Flash, and 3.5 Flash-Lite for model availability, then 2.5 Flash when the newer-model grounding allowance is exhausted. A live current-information query succeeded through `gemini-2.5-flash` with five sources; the newer model returned HTTP 429 on all five configured accounts. Failed accounts are cooled down for five minutes to avoid repeating quota failures. A live request to Wikipedia's public search API returned five source pages for a stable topic. Brave Search remains an optional independent provider; set `BRAVE_SEARCH_API_KEY` in `.env` or the private connector credential store to enable it.

For a requested `inspect_screen` call, Jarvis captures a private JPEG and submits one frame through Gemini Live's supported realtime video input immediately before the OCR tool response. The installed SDK cannot serialize binary image parts inside `send_tool_response`, so the result reports `frame_submitted` only when sending succeeded; that status does not prove the model interpreted the pixels. If capture is missing, oversized, or rejected, the tool returns `ocr_only` and Jarvis should answer only from OCR, window details, and desktop metadata. A synthetic 1×1 JPEG test completed the full Live tool-call, frame, tool-response, and model-turn sequence without real screen or microphone data.

The installed Google token now includes the `drive.readonly` scope. Drive file search and Sheets metadata reads have been verified live; no Google Doc was available for a live read. Docs reads and bounded Sheets cell reads are wired and covered by focused tests, but no live document content was read in this check. If those APIs return an enablement error, enable the **Google Docs API** and **Google Sheets API** for the OAuth project. To reconnect later, say **“open Google authorization”** to Jarvis or run `./.venv/bin/python scripts/connect_google.py` from this repository. The configured redirect URI is `http://localhost:8085/callback`. Uploaded binary formats such as PDFs are not yet parsed; Drive text reads support small plain text, Markdown, CSV, JSON, and XML uploads.
